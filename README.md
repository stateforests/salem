# salem
A small, keyboard-driven window manager for the [River](https://codeberg.org/river/river) compositor, written and configed in [Janet](https://janet-lang.org).\
I deliberated making my own window manager for a while but decided to because River's non-monolithic design lets it stay policy only, which kept everything I need down to 700 lines.\
Thanks to Isaac Freund for [river](https://codeberg.org/river/river) and [janet-wayland](https://codeberg.org/ifreund/janet-wayland) - wouldn't be possible without either of these.
